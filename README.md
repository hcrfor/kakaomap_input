# 📍 카카오맵 엑셀 즐겨찾기 자동 등록기

엑셀 파일(`.xlsx`, `.xls`, `.csv`)에 저장된 **`번호_유형_관리`**, **`위도`**, **`경도`** 데이터를 읽어 카카오맵의 원하는 즐겨찾기 그룹에 일괄 등록해 주는 로컬 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **그룹 · 모양 · 색상 커스터마이징**
   - 새 즐겨찾기 그룹명 입력 (동일 이름 그룹이 있으면 기존 그룹에 이어서 등록)
   - 공개 허용 범위 선택 (`비공개` / `링크공개` / `공개`)
   - 카카오맵 10종 그룹 아이콘 모양 & 7종 마커 색상 선택 + 실시간 미리보기
2. **엑셀 파일 업로드 & 유효성 검증**
   - `번호_유형_관리`, `위도`, `경도` 열 자동 인식 및 좌표 유효성 검사
   - 등록 전 데이터 테이블 미리보기 제공
3. **수동 로그인 + 자동 일괄 등록**
   - 크롬 브라우저로 카카오 로그인 화면을 띄워 사용자가 직접 안전하게 로그인 (QR/2차 인증 지원)
   - 로그인 완료 즉시 그룹 생성 및 좌표별 즐겨찾기 자동 저장
   - 이미 등록된 장소 중복 건너뛰기, 일시적 오류 자동 1회 재시도, 완료 알림 모달 & 실패 항목만 재시도 지원

## ⚠️ 왜 GitHub Pages 등 외부 웹사이트가 아닌 내 PC에서 실행해야 하나요?

- 카카오맵은 보안 정책상 개인 즐겨찾기를 추가하는 공식 외부 API를 제공하지 않습니다.
- 따라서 이 도구는 **내 PC의 실제 크롬 브라우저(Playwright)**를 띄워 사용자가 직접 카카오 로그인을 진행한 뒤 등록 작업을 수행해야 하므로, **반드시 내 PC에서 로컬 웹 서버를 실행**해서 사용해야 합니다.

## 🚀 설치 및 실행 방법

### 준비물
- [Node.js](https://nodejs.org/) (v18 이상 권장)
- Google Chrome 또는 Microsoft Edge 브라우저

### 방법 1: 원클릭 실행 (Windows)
1. 저장소를 내려받습니다:
   ```bash
   git clone https://github.com/hcrfor/kakaomap_input.git
   cd kakaomap_input
   ```
2. 폴더 내 **`run.bat`** 파일을 더블클릭하면 자동으로 패키지 설치 후 서버와 웹 페이지(`http://localhost:3000`)가 열립니다.

### 방법 2: 터미널에서 직접 실행
```bash
npm install
npm start
```
실행 후 브라우저에서 `http://localhost:3000` 으로 접속하세요.
