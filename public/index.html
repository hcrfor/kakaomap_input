💻 다른 PC 설치 & 실행 방법 총정리

1

사전 준비: Node.js 설치 (필수, 최초 1회)

이 프로그램은 Node.js 엔진 위에서 작동합니다. PC에 아직 없다면 먼저 설치해 주세요.

  1. nodejs.org에 접속합니다.
  2. [Get Node.js®] (또는 초록색 LTS 버전) 버튼을 클릭해 설치 파일을 다운로드합니다.
  3. 다운로드된 파일을 실행하고 옵션 변경 없이 [Next] → [Install] 로 기본 설치를 마칩니다.
2

프로그램 실행: run.bat 더블클릭

프로그램 폴더(예: C:\kakaomap_input)로 이동하여 run.bat 파일을 마우스로 더블클릭합니다.

💡 팁: 최초 실행 시 필요한 부품을 인터넷에서 1~2분간 자동으로 설치한 뒤, 브라우저에서 http://localhost:3000 화면이 자동으로 열립니다.
!

자주 발생하는 오류 & 해결 방법 (트러블슈팅)

Q1. 회사/보안망에서 SELF_SIGNED_CERT_IN_CHAIN 에러가 날 때

사내 방화벽/보안 인증서 때문에 다운로드가 차단된 경우입니다. 터미널(CMD) 창에서 아래 명령어 1줄을 치고 엔터를 누른 뒤 다시 npm install을 실행하세요. npm config set strict-ssl false

Q2. 한글 띄어쓰기 경로로 인한 에러가 날 때

폴더 경로에 한글 띄어쓰기(예: D:\한 성 안\산 림\...)가 길면 설치 오류가 날 수 있습니다. 폴더를 C:\kakaomap_input 처럼 단순한 영문 경로로 옮겨서 run.bat를 실행해 주세요.

Q3. "이 페이지에 연결할 수 없습니다"가 뜰 때

검은색 콘솔 창이 닫혀서 서버가 꺼진 상태입니다. 검은색 콘솔 창은 끄지 말고 최소화해 두어야 웹 화면이 정상 동작합니다.
